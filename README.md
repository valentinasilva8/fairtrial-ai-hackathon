```bash
git clone https://github.com/valentinasilva8/fairtrial-ai-hackathon.git

```

## Project Description

Indonesia's ITE Law was used to prosecute journalists and critics, often on complaints from ministers and companies. It was reformed in 2024 and narrowed by the Constitutional Court in 2025, and police promised to comply. We stress-test the reform: we run real prosecutions through the new rules and ask, "Would this case still be allowed today?" Then we track whether promises were kept, and turn each finding into a cited advocacy brief.
